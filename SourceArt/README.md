# Source art

Blender sources live here, outside Unity's imported Assets tree. Export FBX mesh/animation to `Game/Assets/Wings/Art`; keep `.meta` files in version control. Binary source/export files use Git LFS.

`Smoke/reference.blend` is generated by `Tools/blender_smoke.py`: a one-metre rigged cube with a short sway animation. It proves the export/import path and is not bird production art. The first playable bird and landscape use explicitly temporary geometry generated through Unity editor APIs.
